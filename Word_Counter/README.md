## Word Counter

A simple Python program that counts the total number of words in a given text and shows the top 5 most frequently used words.  
It can take input either manually or from a text file.

---

### 🔹 Features
- Counts the total number of words in any text input  
- Displays the 5 most common words and their frequencies  
- Allows input from:
  - Manual text entry  
  - External text file  
- Handles punctuation and capitalization  
- Easy to us
